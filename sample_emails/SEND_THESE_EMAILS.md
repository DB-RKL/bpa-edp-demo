# Sample emails to send to bpa-intake@example.onmicrosoft.com

All synthetic. Send each one **to** `bpa-intake@example.onmicrosoft.com` from any account (your outlook.com address is fine).
The subject must start with `BPA demo`: the pipeline only reads those. Attach the files from this folder where listed.
The email's received time will be when you send it; the dates inside the text are the story dates.

## Email 1
**Subject:** BPA demo - Jesmond Pension Scheme 5 - member movement confirmation
**Attach:** Jesmond5_member_data_pack.xlsx
**Why:** Fills the invalid volume in BI-0002 (Excel says 'approx 120').

```
Hello,

Please note the final number of members moving for Jesmond Pension Scheme 5 is 142. We were first notified on 2026-08-20 and the full documents reached you on 28/08/2026. The member data pack is attached.

Regards,
D. Patel
```
